# Live Wallpaper - Interactive 3D Character Viewer

Интерактивное приложение для Windows/Mac/Linux с живыми обоями - 3D персонажем, который можно деформировать и взаимодействовать с ним.

## Функции

✨ **Интерактивность:**
- **Левый клик** - деформация персонажа в точке клика
- **Левый клик + перетаскивание** - вытягивание части тела
- **Правый клик + движение мышью** - вращение камеры вокруг персонажа
- Камера автоматически возвращается на место через время

🎮 **Управление:**
- 📏 Ползунок размера - масштабирование персонажа (0.5x - 3x)
- 💡 Ползунок освещения - интенсивность света (0 - 3)
- 🔄 Ползунок вращения света - изменение направления света (0° - 360°)
- 🔄 Кнопка "Сбросить позу" - вернуть персонажа в исходное положение
- ▶️ Кнопка "Анимация" - включение/выключение анимации

## Технологический стек

- **Electron** - десктопное приложение
- **Babylon.js** - 3D графика
- **WebGL** - оптимизированная 3D визуализация

## Установка

1. Клонировать репозиторий:
```bash
git clone https://github.com/kusk759/kuskarchive2.0.git
cd live-wallpaper
```

2. Установить зависимости:
```bash
npm install
```

3. Разместить файлы модели в `live-wallpaper/renderer/assets/`:
   - `kusk759 fem2.obj`
   - `kusk759 fem2.mtl`
   - `body6.png`

## Запуск

```bash
npm start
```

Для разработки с DevTools:
```bash
npm run dev
```

## Сборка

```bash
npm run build
```
